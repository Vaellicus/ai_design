# 🚀 Quick Start Guide - Rhino 9 + GitHub Copilot MCP

**Get up and running in 5 minutes!**

---

## Step 1: Install the Plugin (2 minutes)

1. Open **Rhinoceros 9**
2. Run: `PackageManager`
3. Find and install: **Rhino-MCP-Platform**
4. Restart Rhino

---

## Step 2: Configure VS Code (1 minute)

✅ Already done! Files are ready:
- `.vscode/mcp.json` - MCP configuration
- `README.md` - Full documentation
- `TEST_PROMPTS.md` - Test examples
- `SETUP_CHECKLIST.md` - Detailed checklist

Just reload VS Code:
- Press: `Ctrl+Shift+P`
- Select: **Reload Window**

---

## Step 3: Activate Agent Mode (1 minute)

1. Open **Copilot Chat** in VS Code (Ctrl+Shift+I)
2. Find the **mode selector** at top
3. Switch to **Agent** mode
4. See `rhino` in the tool picker ✅

---

## Step 4: Test the Connection (1 minute)

Keep Rhino open, then in Copilot Chat (Agent mode), type:

```
Create a sphere with radius 10 at the origin
```

**Result:** A sphere appears in Rhino! 🎉

---

## 🎯 You're Ready!

Try these next:
- `Create a 3x3 grid of boxes`
- `What's in the current document?`
- `Create a spiral with 10 turns`

See [TEST_PROMPTS.md](./TEST_PROMPTS.md) for 14+ examples.

## 📋 Need Help?

| Issue | Fix |
|-------|-----|
| "Rhino server not found" | Reload VS Code, check you're in Agent mode |
| "No tools available" | Make sure Rhino 9 is running |
| "Command failed" | Restart Rhino, then reload VS Code |
